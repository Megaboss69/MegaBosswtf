Ограничения Lite-версии

  • Девблоги только 240–266 (276–308, 196, 217, SnowRust не поддерживаются).
  • Встроенный HWID-спуфер отсутствует — обход железных банов недоступен.
  • Техническая поддержка по Lite не оказывается.
  • Нет автообновлений под новые девблоги — только ветка 240–266.
  • Подходит для теста и для серверов на 240–266.
